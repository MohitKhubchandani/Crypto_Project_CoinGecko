## 🌟 Features

✅ **Live Cryptocurrency Data** - Fetches real-time data from the CoinGecko API.  
✅ **Interactive UI** - Built with React and Tailwind CSS for a sleek user experience.  
✅ **Fast & Lightweight** - Powered by Vite for optimal performance.  
✅ **Responsive Design** - Works seamlessly across devices.  
✅ **Dark Mode Support** - Enjoy a visually comfortable experience.  

## 🛠 Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Data Source:** CoinGecko API
- **Development Tools:** ESLint, Prettier

## 📥 Installation

### 1️⃣ Clone the repository
```sh
git clone https://github.com/MohitKhubchandani/Crypto_Project_CoinGecko.git
cd Crypto_Project_CoinGecko
```

### 2️⃣ Install dependencies
Using npm:
```sh
npm install
```
Using Yarn:
```sh
yarn install
```

### 3️⃣ Run the development server
Using npm:
```sh
npm run dev
```
Using Yarn:
```sh
yarn dev
```

🔗 Open `http://localhost:3000` in your browser.

## 🔑 API Setup

This project uses the CoinGecko API. Follow these steps:

1. Get an API key from [CoinGecko](https://www.coingecko.com/en/api).
2. Create a `.env` file in the root directory.
3. Add your API key:
```sh
VITE_COINGECKO_API_KEY=your_api_key_here
COINGECKO_API_URL = 'https://api.coingecko.com/api/v3'
```
